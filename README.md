## 1. Requirements

Before using the trainer, make sure you have:

- A Windows PC.
- The PC version of The Last of Us Part II Remastered.
- A keyboard with a numeric keypad.
- The trainer downloaded from the official Nordic Mod Developer release.

**Important:** This trainer is for Windows PC. It cannot run directly on an iPad.

## 2. Downloading the Trainer

1. Open the Nordic Mod Developer GitHub repository.
2. Find the latest release for The Last of Us Part II Remastered Trainer.
3. Download the trainer `.exe` file.
4. Save it somewhere easy to find, such as your Downloads folder.
5. Wait until the download finishes.

Only download files from a source you trust.

## 3. Starting the Game

1. Launch The Last of Us Part II Remastered.
2. Load your save or start a new game.
3. Wait until you can control your character.
4. Keep the game running.

## 4. Starting the Trainer

1. Find the downloaded trainer `.exe` file.
2. Double-click the file to launch it.
3. If Windows shows a security warning, verify the file's source before deciding whether to continue.
4. Keep the trainer running while you play.
5. Return to the game and try the relevant keyboard shortcut.

The trainer's exact behaviour may depend on its build and your game version.

## 7. Troubleshooting

### The trainer will not open
- Check that the download completed successfully.
- Confirm that you downloaded the correct file.
- Verify the file's source if Windows displays a security warning.

### The keyboard shortcuts do not work
- Start the game first.
- Launch the trainer after the game has loaded.
- Click the game window before using a shortcut.
- Check Num Lock and use the numeric keypad.

### Some features do not work
- Check that your game version is compatible.
- Confirm that the shortcuts match this trainer's build.
- Some features may only work in certain situations.

### The game crashes
- Close the game and trainer.
- Start the game without the trainer to check whether the problem continues.
- Back up your saves before trying again.
